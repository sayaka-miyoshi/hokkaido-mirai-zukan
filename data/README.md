# データファイル

## 学校マスター.csv

Googleスプレッドシートの **「学校マスター」** シートへ取り込むマスターデータです。

1. スプレッドシートでシート「学校マスター」を作成（または既存を選択）
2. **ファイル → インポート → アップロード** で `学校マスター.csv` を選択
3. インポート先: **現在のシートを置換**（1行目ヘッダーから入れる）
4. 手順は `docs/スプレッドシート_学校マスター.md` の数式セットアップへ進む

新しい学校を追加するときは **このCSVに1行追加 → 再インポート** またはスプレッドシート上で行追加のみでも可（本シートの O・P 列は数式のため全記事へ自動反映）。

## slug-snapshot.json

本番CSVから取得した **既存 slug のスナップショット**（2026/6/4時点・44件）。  
N列を誤って変更していないか `npm run verify:slugs` で確認できます。

## slug候補

`slug候補` 列はスプレッドシート上の **Y列のみ**。サイトが読むのは **N列 `slug`** だけです。

## 動画カテゴリマスター.csv

Googleスプレッドシートの **「動画カテゴリマスター」** シートへ取り込むマスターデータです。

- **A列 ID** … シート1 G列「動画カテゴリ」に保存する値
- **B列 表示名** … サイト上に表示する日本語名

手順は `docs/スプレッドシート_動画カテゴリマスター.md` を参照。
