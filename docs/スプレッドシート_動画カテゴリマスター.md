# 動画カテゴリマスター

## 概要

動画カテゴリを **ID（内部値）** と **表示名（サイト表示）** で管理します。

| 保存場所 | 内容 |
|---------|------|
| **シート1 G列「動画カテゴリ」** | ID（例: `club-intro`） |
| **動画カテゴリマスター** | ID ↔ 表示名の対応表 |
| **サイト** | 表示名のみ表示（IDは非表示） |

---

## 列構成

| A | B |
|---|---|
| **ID** | **表示名** |

- **ID:** 英小文字 + ハイフン（例: `school-intro`, `company-visit`）
- **表示名:** サイト・フィルタチップに表示する日本語名

マスターCSV: `data/動画カテゴリマスター.csv`

---

## スプレッドシートへのセットアップ

1. シート **「動画カテゴリマスター」** を新規作成
2. **ファイル → インポート** で `data/動画カテゴリマスター.csv` を取り込み
3. **ファイル → 共有 → ウェブに公開** → シート「動画カテゴリマスター」を CSV で公開
4. `.env.local` に公開 URL を設定（任意）:

   ```
   NEXT_PUBLIC_VIDEO_CATEGORY_CSV_URL=https://docs.google.com/spreadsheets/d/e/xxxxx/pub?gid=yyyy&single=true&output=csv
   ```

   未設定の場合はリポジトリ同梱の CSV を使用します。

5. **シート1 G列** を ID に移行（下記「移行手順」）

---

## シート1 G列の入力規則（プルダウン）

1. 動画カテゴリマスターの **A列（ID）** を範囲指定（例: `動画カテゴリマスター!A2:A100`）
2. シート1 **G列** にデータの入力規則 → **プルダウン（リスト）** を設定
3. 運用者は **ID** を選ぶ（表示名はマスター側で管理）

---

## 移行手順（表示名 → ID）

本番シート1がまだ **表示名**（例: `部活紹介`）の場合:

1. 動画カテゴリマスターをインポート
2. G列の値をマスター B列（表示名）と照合し、対応する A列（ID）に置換  
   例: `部活紹介` → `club-intro`
3. プルダウンを ID 列に切り替え

**後方互換:** 移行完了前も、アプリは表示名を ID に自動変換して表示します。
