## 設計原則（循環参照を防ぐ）

```mermaid
flowchart LR
  SM[学校マスター]
  CM[部活マスター]
  EM[企業マスター]
  S1[シート1 メインデータ]

  SM -->|参照のみ| S1
  CM -->|参照のみ| S1
  EM -->|参照のみ| S1
```

| OK | NG |
|----|-----|
| シート1 → 各マスターを **VLOOKUP / INDEX+MATCH** | マスターが **シート1の列を参照** |
| マスターは **手入力・プルダウン** で更新 | IMPORTRANGE でシート1とマスターを **相互参照** |
| 部活 Q・X は **A列＋B列を直接照合**（XLOOKUP） | 部活マスター **E列キー** を Q・X の数式で参照 |

**以前の循環参照:** シート1 → 部活マスター生成 → シート1 がその結果を参照 → エラー。  
**現在:** マスターは独立。シート1はマスターを **読むだけ**。

## 数式セットアップ（①②③）— 参照用

### 事前準備（部活マスター A〜D）

1. **A列 部活名・B列 学校名** の組み合わせを登録（重複のない表記）
2. **C列 競技カテゴリ・D列 部活SNS** を入力
3. E列キーは **任意**（Q/X の数式では参照しない）

---

### ① 競技カテゴリ（X列）— 確定

**X2** に貼り付け（X3 以降は空でOK）。**部活マスター E列は使わない。**

```gs
=ARRAYFORMULA(IF(LEN($E2:$E)=0;"";MAP($E2:$E;$D2:$D;LAMBDA(e;d;IFERROR(XLOOKUP(TRIM(e)&"|"&TRIM(d);TRIM('部活マスター'!$A$2:$A)&"|"&TRIM('部活マスター'!$B$2:$B);'部活マスター'!$C$2:$C);"")))))
```

- 照合: **部活名（E）＋学校名（D）** → 部活マスター **A列|B列**
- 取得: 部活マスター **C列（競技カテゴリ）**
- 部活名だけの VLOOKUP は **使わない**（別校の同名部活で誤取得）

---

### ② 部活SNS（Q列）

**Q2** に貼り付け（Q3 以降は空でOK）。**Q2 が空だと Q 列全体が空**になるので必須。照合は X と同じ（A+B 直接）。

```gs
=ARRAYFORMULA(IF(LEN($E2:$E)=0;"";MAP($E2:$E;$D2:$D;LAMBDA(e;d;IFERROR(XLOOKUP(TRIM(e)&"|"&TRIM(d);TRIM('部活マスター'!$A$2:$A)&"|"&TRIM('部活マスター'!$B$2:$B);'部活マスター'!$D$2:$D);"")))))
```

- 照合: X と同じ（A列|B列）
- 取得: 部活マスター **D列（部活SNS）**

---

### ③ slug候補（Y列・新規）

**N列 slug は触らない。** 既存行（例: `sapporo-fire-school`）はそのまま。

1. **X列の右**に列追加 → **Y1** = `slug候補`
2. **Y2**（**Y2 未設定だと slug候補が全行空**）:

```gs
=ARRAYFORMULA(
 IF((LEN($N2:N)>0)+(LEN($A2:A)=0),"",
  MAP($A2:A,$D2:D,$E2:E,$F2:F,
    LAMBDA(a,d,e,f,
      TRIM(REGEXREPLACE(
        LOWER(REGEXREPLACE(REGEXREPLACE(
          GOOGLETRANSLATE(TEXTJOIN(" ",TRUE,d,e,f,a),"ja","en"),
          "[^a-zA-Z0-9 -]",""
        )," +","-")),
        "-+$",""
      ))
    )
  )
 )
)
```

**運用:** Y列で候補確認 → 確定したら **N列に値のみ貼り付け**。N が空の間だけ Y に候補が出る。
