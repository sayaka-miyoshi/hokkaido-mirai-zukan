# iSTEP 初回導入 — カテゴリ選択型（Week 1）

**目的:** Instagramコメント → iSTEP自動DM → 北海道未来図鑑へ誘導する初期導線  
**方針:** 大量キーワードは使わず、シンプルなカテゴリ選択（4ボタン）で開始  
**キャンペーン:** `launch_week1`  
**本番サイト:** https://www.hokkaido-miraizukan.jp/  
**関連ファイル:** `exports/istep-launch-week1.csv`

---

## 1. パッケージ文面（そのままコピー可）

iSTEPの「パッケージ管理」に登録する本文です。

```
コメントありがとうございます😊

北海道未来図鑑へようこそ！

知りたい情報を選んでください✨

🎓 学校を探す
⚽ 部活を探す
🏢 企業を探す
🏛️ 札幌市・行政の情報を見る
```

**補足（任意・本文に足す場合）**

```
ボタンを押すと、北海道未来図鑑のページが開きます。
```

## 2. 4つのボタン用URL（UTM付き）

すべて共通パラメータ:

| パラメータ | 値 |
|------------|-----|
| `utm_source` | `istep` |
| `utm_medium` | `dm` |
| `utm_campaign` | `launch_week1` |

ボタン識別用に `utm_content` と `dm_group` も付与しています（GA4でボタン別計測可能）。

| ボタン表示名 | 遷移先の意味 | URL（登録用・そのままコピー） |
|--------------|--------------|------------------------------|
| 🎓 学校を探す | 学校一覧 | `https://www.hokkaido-miraizukan.jp/schools?utm_source=istep&utm_medium=dm&utm_campaign=launch_week1&utm_content=schools&dm_group=entry:schools` |
| ⚽ 部活を探す | 部活一覧 | `https://www.hokkaido-miraizukan.jp/clubs?utm_source=istep&utm_medium=dm&utm_campaign=launch_week1&utm_content=clubs&dm_group=entry:clubs` |
| 🏢 企業を探す | 企業一覧 | `https://www.hokkaido-miraizukan.jp/companies?utm_source=istep&utm_medium=dm&utm_campaign=launch_week1&utm_content=companies&dm_group=entry:companies` |
| 🏛️ 札幌市・行政の情報を見る | 札幌エリア記事一覧 | `https://www.hokkaido-miraizukan.jp/area/sapporo?utm_source=istep&utm_medium=dm&utm_campaign=launch_week1&utm_content=sapporo_gov&dm_group=entry:sapporo` |

### 札幌市・行政 URL の選定理由

現状、サイトに「行政専用一覧ページ」はありません。

| 候補 | URL | 判定 |
|------|-----|------|
| **札幌エリアページ（採用）** | `/area/sapporo` | 札幌の学校・部活・企業・行政関連記事がまとまる。行政・自治体ジャンルの記事も含まれる |
| トップ検索 | `/` | ジャンル絞り込みのURLパラメータ非対応のため不向き |
| `/start` | `/start` | カテゴリ選択ページ自体。パッケージの着地としては重複しやすい |

**採用:** `https://www.hokkaido-miraizukan.jp/area/sapporo`（上記UTM付き）

将来「行政・自治体」専用一覧を作った場合は、このボタンURLだけ差し替えてください。

## 3. iSTEP 登録手順（初心者向け）

画面名称はiSTEPのバージョンで多少異なる場合があります。近いメニュー名で読み替えてください。

### 全体の流れ

```
① パッケージ管理で「文面＋4ボタン」を作る
　　↓
② 自動返信管理で「キーワード → そのパッケージ」を紐づける
　　↓
③ Instagramでテストコメント → DMが届くか確認
　　↓
④ ボタンを押して未来図鑑が開き、GA4で計測されるか確認
```

---

### Step A. パッケージ管理で作る内容

1. iSTEP管理画面にログインする  
2. **パッケージ管理**（または「メッセージパッケージ」「テンプレート」）を開く  
3. **新規作成**  
4. パッケージ名（管理用）を入力する  

**パッケージ名の例**

```
【初回】カテゴリ選択_launch_week1
```

5. **本文**に、上記「1. パッケージ文面」をそのまま貼り付ける  
6. **ボタン（リンクボタン）を4つ**追加する  

| 順番 | ボタンラベル | リンクURL |
|------|--------------|-----------|
| 1 | 🎓 学校を探す | （2章の学校URL） |
| 2 | ⚽ 部活を探す | （2章の部活URL） |
| 3 | 🏢 企業を探す | （2章の企業URL） |
| 4 | 🏛️ 札幌市・行政の情報を見る | （2章の札幌URL） |

7. 保存する  

**ポイント**

- ボタンラベルは絵文字付きのままでOK（Instagram上で見やすい）  
- URLは改行やスペースを入れない（CSVからコピー推奨）  
- パッケージは「1つ」だけ作り、複数キーワードから同じパッケージを呼び出す  

---

### Step B. 自動返信管理で設定する内容

1. **自動返信管理**（または「キーワード返信」「オートリプライ」）を開く  
2. **新規作成**  
3. 次を設定する  

| 項目 | 設定内容 |
|------|----------|
| 返信タイプ | パッケージを送信 |
| 使用パッケージ | `【初回】カテゴリ選択_launch_week1` |
| キーワード条件 | 下記「キーワード条件」参照 |
| 有効 / 無効 | **有効** |
| おすすめ設定 | ON推奨（コメント欄に出やすくなる場合あり） |

4. キーワードを **1件ずつ** 登録する（まとめて登録できる場合はCSVのキーワード列を利用）  
5. 保存する  

**同じパッケージを使うキーワードは、すべて同じ返信内容になります。**  
（学校・部活・ラクロスなど、どのキーワードでも4ボタンの選択画面が届く）

---

### Step C. キーワード条件

#### マッチ方式（推奨）

| 設定 | 推奨値 | 理由 |
|------|--------|------|
| 一致条件 | **部分一致** または **完全一致** | 初回は誤爆を減らすなら完全一致。取りこぼしを減らすなら部分一致 |
| 大文字小文字 | 区別しない | 日本語中心のため影響小 |
| 対象 | コメント本文 | 投稿へのコメントがトリガー |

**初回のおすすめ:** まず **完全一致** で10〜20語だけ登録し、反応を見てから部分一致や語数を増やす。

### Step D. ボタン設定チェックリスト

- [ ] ボタンが **4つ** ある  
- [ ] ラベルが文面の4行と対応している  
- [ ] 各URLに `utm_source=istep` が入っている

- [ ] スマホのInstagram内ブラウザでも開ける

### Step E. テスト方法

#### 1. 自分のアカウントでコメントテスト

1. 対象のInstagram投稿を開く（運用アカウントの投稿）  
2. テスト用キーワードをコメントする（例: `学校`）  
3. 数秒〜1分以内に **DMが届く** ことを確認  
4. パッケージ文面が正しいことを確認  
5. 4つのボタンが表示されることを確認  

#### 2. ボタン遷移テスト

| ボタン | 期待されるページ |
|--------|------------------|
| 学校を探す | `/schools`（学校一覧） |
| 部活を探す | `/clubs`（部活一覧） |
| 企業を探す | `/companies`（企業一覧） |
| 札幌市・行政の情報を見る | `/area/sapporo`（札幌エリア） |

#### 3. GA4 計測テスト

1. [Google Analytics](https://analytics.google.com) → プロパティ **G-9Q0MGFPBZ6**  
2. **レポート → リアルタイム** を開く  
3. ボタンを押してサイトを開く  
4. リアルタイムにユーザーが表示されることを確認  
5. 可能ならイベント / ページパスに `/schools` などが含まれることを確認  

**流入元の見分け方（後からレポートで見る場合）**

| ディメンション | 期待値 |
|----------------|--------|
| セッションの参照元 / メディア | `istep` / `dm` |
| キャンペーン | `launch_week1` |
| 手動のコンテンツ（utm_content） | `schools` / `clubs` / `companies` / `sapporo_gov` |

#### 4. うまくいかないとき

| 症状 | 確認すること |
|------|----------------|
| DMが来ない | 自動返信が「有効」か / キーワード完全一致か / iSTEPとInstagram連携が有効か |
| ボタンが無い | パッケージにボタンを追加したか / パッケージ送信になっているか |
| ページが404 | URLのコピーミス・全角文字・改行が入っていないか |
| GA4に出ない | 測定IDが `G-9Q0MGFPBZ6` か / 広告ブロックをオフにして再テスト |

---

## 4. 運用ルール（安全運用）

1. **Week 1 は上記18語までに限定**する（誤爆・運用負荷を抑える）  
2. 反応を見てから競技・学校名を追加する  
3. 個別記事URLへの直リンクは、慣れてから（Phase 2）  
4. キーワード追加時も **同じパッケージ** を使い、ボタン構成は変えない  
5. URLを変えるときはパッケージのボタンだけ更新すればよい（キーワード側は触らない）
