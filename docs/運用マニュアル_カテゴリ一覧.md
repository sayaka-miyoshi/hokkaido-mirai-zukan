# カテゴリ運用マニュアル

**対象:** Googleスプレッドシート「学校・部活検索データ」シート1  
**更新:** 2026/5/31（本番CSV 282行・タイトルあり 282件時点）

---

## 3種類のカテゴリの違い

| 種類 | シート1列 | 役割 | マスター | サイトでの見え方 |
|------|-----------|------|----------|------------------|
| **ジャンル** | **B列** | 記事の**大分類**（誰のコンテンツか） | なし（プルダウン推奨） | カード左上の色付きバッジ・トップの大きいフィルタ |
| **動画カテゴリ** | **G列** | 動画・記事の**内容の種類** | **動画カテゴリマスター**（ID＋表示名） | カード下部ラベル・「動画カテゴリ」フィルタ |
| **進路カテゴリ** | **H列** | **進路・業界**のタグ（任意） | なし（自由入力） | 詳細ページ・「進路カテゴリ」フィルタ |

**覚え方**

- **ジャンル** … 「学校記事？ 部活？ 行政？」
- **動画カテゴリ** … 「部活紹介？ 工場見学？ 観光スポット？」
- **進路カテゴリ** … 「公務員向け？ 食品業界向け？」（空欄でも可）

## 1. ジャンル（B列）

### 定義

取材・掲載記事の**主体**を表す大分類です。  
学校名・部活名・企業名（団体名）のどれを主キーにするかを決めるときの基準にもなります。

### 入力ルール

- **1記事につき1つ**（必須）
- 表記は下表の**正式名称**と完全一致（余分なスペース不可）
- トップページの大ボタン（🏫学校 / ⚽部活 / 🏢企業）に対応するのは **学校・部活・企業訪問** の3つ  
  → **観光・行政・自治体・イベント** はサイトに表示されますが、現状トップの大ボタンには未対応（グレーバッジ）

### 正式一覧（運用で使う値）

| ジャンル | 件数（参考） | いつ使うか | 主に入力する列 | 具体例（実データ） |
|----------|-------------|-----------|---------------|-------------------|
| **学校** | 63 | 学校自体の紹介・OC・寮・学科 | D列 学校名 | 札幌消防学校／北海道科学大学 YOSAKOI |
| **部活** | 41 | 部活動・サークル・競技 | D列 学校名 ＋ E列 部活名 | 北海学園大学女子ラクロス部 |
| **企業訪問** | 95 | 民間企業・工場・商店の取材 | F列 企業名 | 人形浄瑠璃／日本最北の煉瓦工場 |
| **観光** | 61 | 観光施設・体験・グルメ・名所 | F列 施設・事業者名（または D列） | 標津で体験出来るオススメ5選 |
| **行政・自治体** | 12 | 市役所・消防・自衛隊・公共機関 | F列 団体名 | 札幌市図書情報館の休館日に密着 |
| **イベント** | 4 | 祭り・大会・単発イベント（主体が横断的） | 主催に合わせて D/F | 北海道初eスポーツ世界大会 |

### 選び方フロー

```
学校の公式な紹介・OC・学科      → 学校
部活・サークル・競技            → 部活
民間の会社・工房・店舗          → 企業訪問
観光地・体験・リゾート          → 観光
消防・市役所・自衛隊・公共      → 行政・自治体
雪まつり・フェス・単発イベント  → イベント
```

### 移行メモ

- 以前 **企業訪問** に入れていた消防・行政系は **行政・自治体** へ順次移行中
- ジャンル **空欄** の行が残っている場合は、内容を確認して上記いずれかを設定

### サイト連携（参考）

| ジャンル | トップ大ボタン | バッジ色 | 詳細ページURL |
|----------|---------------|---------|--------------|
| 学校 | ✅ 学校 | 青 | `/school/[slug]`（D列＋slug） |
| 部活 | ✅ 部活 | 緑 | `/club/[slug]`（E列＋slug） |
| 企業訪問 | ✅ 企業 | 橙 | `/company/[slug]`（F列＋slug） |
| 観光 | — | 灰 | 一覧・詳細のみ |
| 行政・自治体 | — | 灰 | 一覧・詳細のみ（F列＋slug で company 相当） |
| イベント | — | 灰 | 一覧・詳細のみ |

## 2. 動画カテゴリ（G列）

### 定義

Instagram リール等の**動画・記事の内容タイプ**を表します。  
ジャンル（誰）とは独立して、「どんな内容か」をユーザーが絞り込むためのラベルです。

### 入力ルール

| 項目 | ルール |
|------|--------|
| **保存値** | マスターの **ID**（例: `club-intro`）を G列に入力 |
| **表示名** | マスター B列。サイトでは ID ではなく表示名のみ表示 |
| **新規追加** | 先に **動画カテゴリマスター** に ID＋表示名を追加 → G列プルダウン範囲を更新 |
| **空欄** | 可（フィルタに出ない） |

詳細手順: `docs/スプレッドシート_動画カテゴリマスター.md`

### マスター一覧（リポジトリ正式版）

G列プルダウン・新規記事は **ID 列** から選択してください。

## 3. 進路カテゴリ（H列）

### 定義

記事を見た人（学生・保護者）の**進路・業界**に関連付ける任意タグです。  
「この記事はどんな将来像・業界に関心がある人向けか」を示します。

### 入力ルール

| 項目 | ルール |
|------|--------|
| **必須** | いいえ（**空欄が約57%** — 問題なし） |
| **マスター** | なし（自由入力） |
| **表記** | **業界・職種** を `・` でつなぐ形式を推奨（例: `食品・製造`） |
| **追加** | 新しい業界が出たらそのまま入力可。似た表記は既存に寄せる |

### ジャンル別の入力目安

| ジャンル | 進路カテゴリの付け方 |
|----------|---------------------|
| 学校 | 学科・進学先に合わせる（例: 消防学校 → `公務員`） |
| 部活 | 空欄でも可。スポーツ系企業取材なら `スポーツ関連業界` |
| 企業訪問 | **その企業の業界**（例: キリン → `食品・製造`） |
| 観光 | `観光・ホテル` または空欄 |
| 行政・自治体 | `公務員` |
| イベント | 主催・内容に合わせるか空欄 |

### 表記ゆれを避けるために

| 避けたい | 推奨 |
|---------|------|
| 製造・ものづくり / 工学・ものづくり 混在 | **`工学・ものづくり`** に統一 |
| 食品・農業 / 食品・製造 | 内容に近い方を選択（製造現場 → `食品・製造`） |
| 進学 | 学校紹介全般では空欄でも可。大学進学特集なら **`教育`** |
