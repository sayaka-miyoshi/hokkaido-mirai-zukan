# スプレッドシート数式一覧（コピペ用）

**参照の向き:** マスター → シート1 のみ。マスターに `シート1!` を含む式は入れない。

**N列 slug:** 数式禁止。既存値は変更しない。自動案は **Y列 slug候補** のみ。

---

## 部活マスター（E列キー）

| セル | 数式 |
|------|------|
| E1 | `キー`（テキスト） |
| E2〜 | `=TRIM(A2)&"|"&TRIM(B2)` |

## シート1

### O2 学校公式サイト（既存）

```gs
=ARRAYFORMULA(IF(LEN($D2:D)=0,"",IFERROR(VLOOKUP(TRIM($D2:D),学校マスター!$A$2:$C,2,FALSE),"")))
```

### P2 学校SNS（既存）

```gs
=ARRAYFORMULA(IF(LEN($D2:D)=0,"",IFERROR(VLOOKUP(TRIM($D2:D),学校マスター!$A$2:$C,3,FALSE),"")))
```

### Q2 部活SNS（部活マスター **D列**）— 正式版

**Q2 のみ**に貼り付け（Q3 以降は空）。O・P と同じ VLOOKUP + 複合キー方式。

```gs
=ARRAYFORMULA(IF(LEN($E2:$E)=0,"",IFERROR(VLOOKUP(TRIM($E2:$E)&"|"&TRIM($D2:$D),{'部活マスター'!$E$2:$E,'部活マスター'!$D$2:$D},2,FALSE),"")))
```

- 照合: `E列部活名|D列学校名` ＝ 部活マスター **E列**
- 取得: 部活マスター **D列（部活SNS）**

### X2 競技カテゴリ（部活マスター **C列**）— 正式版

**X2 のみ**に貼り付け（X3 以降は空）。Q2 と同じ照合・参照列だけ C。

```gs
=ARRAYFORMULA(IF(LEN($E2:$E)=0,"",IFERROR(VLOOKUP(TRIM($E2:$E)&"|"&TRIM($D2:$D),{'部活マスター'!$E$2:$E,'部活マスター'!$C$2:$C},2,FALSE),"")))
```

※ Q だけ空のとき → まず **Q2 に式があるか** を確認 → `docs/トラブルシュート_Q列_部活SNS.md`

### Y1 ヘッダー

`slug候補`

### Y2 slug候補（③・N列は触らない）— 正式版

**Y2 のみ**に貼り付け（Y3 以降は空）。N に slug がある行は空表示（既存保護）。

`GOOGLETRANSLATE` は **行ごと** に評価するため **MAP + LAMBDA** を使います（列全体を一度に `GOOGLETRANSLATE` しない）。

```gs
=ARRAYFORMULA(
 IF((LEN($N2:N)>0)+(LEN($A2:A)=0),"",
  MAP($A2:A,$D2:D,$E2:E,$F2:F,
    LAMBDA(a,d,e,f,
      TRIM(REGEXREPLACE(
        LOWER(REGEXREPLACE(REGEXREPLACE(
          GOOGLETRANSLATE(TEXTJOIN(" ",TRUE,d,e,f,a),"ja","en"),
          "[^a-zA-Z0-9 -]",""
        )," +","-")),
        "-+$",""
      ))
    )
  )
 )
)
```

`MAP` 不可時は **Y2 のみ**（下にコピー）:

```gs
=IF($N2<>"","",IF($A2="","",TRIM(REGEXREPLACE(LOWER(REGEXREPLACE(REGEXREPLACE(GOOGLETRANSLATE(TEXTJOIN(" ",TRUE,$D2,$E2,$F2,$A2),"ja","en"),"[^a-zA-Z0-9 -]","")," +","-")),"-+$",""))))
```

※ slug候補が全行空 → `docs/トラブルシュート_Y列_slug候補.md`

### N列

**数式を入れない。** 手入力または Y列からの値のみ貼り付け。

## 数式セル一覧（シート1・必須）

| セル | 列 | 内容 | 備考 |
|------|-----|------|------|
| **O2** | 学校公式サイト | ARRAYFORMULA | 下の行は空 |
| **P2** | 学校SNS | ARRAYFORMULA | 下の行は空 |
| **Q2** | 部活SNS | ARRAYFORMULA | **Q2 だけ**。未設定だと Q 列全体が空 |
| **X2** | 競技カテゴリ | ARRAYFORMULA | **X2 だけ** |
| **Y2** | slug候補 | ARRAYFORMULA | N 空欄行のみ表示 |
| N2〜 | slug | **数式禁止** | 手入力または Y から値のみ貼り付け |

部活マスター **E2** に `=TRIM(A2)&"|"&TRIM(B2)` を入れ、下までコピー。

## 新規行の slug 確定手順

1. D/E/F/A を入力（**N は空**）
2. Y列に slug候補が出る
3. 目視で修正
4. Y列の値をコピー → **N列に値のみ貼り付け**
5. N に入ると Y は空になる（仕様）
