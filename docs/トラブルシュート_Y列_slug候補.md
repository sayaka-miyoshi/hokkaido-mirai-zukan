# Y列（slug候補）が空になるとき

## 診断の順番

### 1. Y2 に数式があるか（最優先）

**Y2 セルが空**だと、slug が未確定の行すべてで slug候補が出ません（Q2 と同じく **Y2 のみ** に ARRAYFORMULA を入れる）。

公開 CSV で `slug候補` 列が **0 件すべて空** → **Y2 未設定** の可能性が高いです。

### 2. 数式の種類が正しいか

次の式は **動きません**（GOOGLETRANSLATE は行ごとに評価する必要がある）:

```gs
GOOGLETRANSLATE(TEXTJOIN(" ",TRUE,$D2:D,$E2:E,$F2:F,$A2:A),"ja","en")
```

正式版は **MAP + LAMBDA** で 1 行ずつ翻訳します → `docs/スプレッドシート_数式一覧.md` の Y2 を使用。

### 3. 行の条件

| 条件 | slug候補 |
|------|----------|
| N列 slug に値あり | **空**（仕様・既存保護） |
| N 空・A列（投稿タイトル）空 | 空 |
| N 空・タイトルあり | 候補を表示 |

### 4. GOOGLETRANSLATE の制限

- 初回は数秒かかることがある
- エラー時はセルが空または `#ERROR!`
- 固有名詞は候補を **目視で直してから N 列へ値のみ貼り付け**

---

## 正式版 Y2 式

**Y2**（Y3 以降は空）:

```gs
=ARRAYFORMULA(
 IF((LEN($N2:N)>0)+(LEN($A2:A)=0),"",
  MAP($A2:A,$D2:D,$E2:E,$F2:F,
    LAMBDA(a,d,e,f,
      TRIM(REGEXREPLACE(
        LOWER(REGEXREPLACE(REGEXREPLACE(
          GOOGLETRANSLATE(TEXTJOIN(" ",TRUE,d,e,f,a),"ja","en"),
          "[^a-zA-Z0-9 -]",""
        )," +","-")),
        "-+$",""
      ))
    )
  )
 )
)
```

`MAP` が使えない場合は **Y2 のみ**（下にコピー）:

```gs
=IF($N2<>"","",IF($A2="","",TRIM(REGEXREPLACE(LOWER(REGEXREPLACE(REGEXREPLACE(GOOGLETRANSLATE(TEXTJOIN(" ",TRUE,$D2,$E2,$F2,$A2),"ja","en"),"[^a-zA-Z0-9 -]","")," +","-")),"-+$",""))))
```
