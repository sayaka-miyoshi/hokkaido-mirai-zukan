# Q列（部活SNS）が空になるとき

## 診断の順番

### 1. Q2 に数式があるか（最優先）

**Q2 セルが空**だと、Q 列全体が空のままになります（ARRAYFORMULA は **Q2 のみ** に入れる）。

- X 列は入るのに Q だけ空 → **Q2 未設定** のことが多い（部活マスターは正常でも表示されない）
- 対処: 下の正式版を **Q2 に貼り付け**（Q3 以降は空のまま）

### 2. 部活マスター D列に URL があるか

X 列が入っているのに Q だけ空で、**Q2 には式がある**場合 → 部活マスター **D列（部活SNS）** が空の可能性。

---

## 部活マスターの正しい列順（必須）

| 列 | 項目 | Q/X が読む列 |
|----|------|-------------|
| A | 部活名 | 照合 |
| B | 学校名 | 照合 |
| **C** | **競技カテゴリ** | **X列** |
| **D** | **部活SNS** | **Q列** |
| E | キー `=A2&"|"&B2` | 照合用 |

### よくあるミス

初期取り込み時は **C=部活SNS / D=競技** の並びだったことがあります。  
ヘッダーだけ入れ替えて **データを D列に移していない** と、Q は常に空になります。

**確認:** 部活マスターで `フォーミュラ部` かつ `北海道大学` の行を開き、

- **C列** … `フォーミュラ` など（競技名）
- **D列** … Instagram URL があるか

SNS が **C列** にだけ入っている場合は、**D列へコピー**してください。

---

## 照合キー（E列）

シート1側: `E列部活名 & "|" & D列学校名`  
部活マスター E列: `=A2&"|"&B2`

期待値: `フォーミュラ部|北海道大学`

- 前後スペースがあると不一致 → 下の式では `TRIM` を使用
- B列が空（部活名だけ登録）だと X も Q も空

---

## 正式版 Q2 式（動作確認済み）

**Q2**（Q3 以降は空）:

```gs
=ARRAYFORMULA(IF(LEN($E2:$E)=0,"",IFERROR(VLOOKUP(TRIM($E2:$E)&"|"&TRIM($D2:$D),{'部活マスター'!$E$2:$E,'部活マスター'!$D$2:$D},2,FALSE),"")))
```

**X2**（参考・C列・Q と同じ方式）:

```gs
=ARRAYFORMULA(IF(LEN($E2:$E)=0,"",IFERROR(VLOOKUP(TRIM($E2:$E)&"|"&TRIM($D2:$D),{'部活マスター'!$E$2:$E,'部活マスター'!$C$2:$C},2,FALSE),"")))
```

### やってはいけない式

```gs
VLOOKUP(E2:E, 部活マスター!A:C, 3, FALSE)
```

- **部活名だけ**照合（学校が違う同名部活で誤取得）
- 範囲が **A:C まで**（D列の部活SNSを読めない）

---

## 部活マスター E列の式（循環参照なし）

```gs
=TRIM(A2)&"|"&TRIM(B2)
```

`シート1!` を参照しないこと。

---

## PCで再確認

```bash
npm run verify:autofill -- 北海道大学 フォーミュラ部
```

D列を直したあと、スプレッドシートを保存し CSV 公開を確認してから再実行してください。
