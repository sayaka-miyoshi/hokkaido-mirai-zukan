# 新規記事1件 — 自動入力テスト手順

## 前提

- 学校マスター・部活マスターにテスト用の学校・部活が登録済み
- シート1の **O2・P2・Q2・X2** に ARRAYFORMULA が入っていること（**Q2 未設定だと Q 列全体が空**）
- **N列 slug** は空で新規行を追加
- **Y列 slug候補** は任意（N確定前の確認用）

## テスト用データ例

| 項目 | 値 |
|------|-----|
| 学校名（D） | `星槎道都大学`（学校マスター登録済み） |
| 部活名（E） | 部活マスターにある組み合わせ（例: 該当部活＋同じ学校名） |
| ジャンル | `部活` |
| slug（N） | **空のまま** |

期待値（マスター次第）:

| 列 | 期待 |
|----|------|
| O 学校公式サイト | `https://www.seisadohto.ac.jp/` |
| P 学校SNS | マスター C列の値（空なら空） |
| Q 部活SNS | 部活マスター D列 |
| X 競技カテゴリ | 部活マスター C列 |

---

## 手順A（スプレッドシート上）

1. シート1の **最終行の下** に1行追加
2. 最低限入力: **投稿タイトル / ジャンル / エリア / 学校名 / 部活名 / 投稿日 / 説明文**
3. **N列 slug は空**
4. 数秒待つ（数式・GOOGLETRANSLATE の再計算）
5. **O・P・Q・X** が期待どおりか目視確認
6. テスト行の **公開** を `非公開` にしておく（本番に出したくない場合）

### 合格基準

- [ ] O列に学校公式サイトURL
- [ ] P列がマスターと一致（未登録なら空でも可）
- [ ] Q列が部活マスターの部活SNSと一致
- [ ] X列が部活マスターの競技カテゴリと一致
- [ ] N列はまだ空（または手動で確定した slug のみ）
- [ ] `#REF!` `#N/A` が出ていない

### よくある失敗

| 症状 | 原因 |
|------|------|
| O・P が空 | 学校名がマスター A列と1文字違い |
| Q だけ空（X は入る） | **Q2 に数式がない**、または部活マスター D列が空 |
| Q・X が空 | 部活名＋学校名の組がマスター A・B に無い、または表記ゆれ |
| 循環参照 | マスターがシート1を参照している |

---

## 手順B（PCでCSV確認）

スプレッドシート保存後:

```bash
cd "06_個人プロジェクト/学校・部活検索HP"
npm run verify:autofill
```

最終行付近の **学校公式サイト / 学校SNS / 部活SNS / 競技カテゴリ** を表示します。

公開CSVの反映後:

```bash
npm run test:csv
npm run verify:slugs
```

- `test:csv` … 接続・件数
- `verify:slugs` … **既存44件の slug が変わっていないこと**

---

## 手順C（サイト表示）

```bash
npm run dev
```

1. http://localhost:3000 を開く
2. 件数が1件増えているか（非公開なら増えない → テスト行は `公開` にするか、件数は据え置きでフィールドのみ確認）
3. 該当投稿の詳細 `/post/[id]` で外部リンク表示を確認

---

## テスト後

- テスト行を削除するか、**公開=非公開** のまま残す
- slug を確定した場合のみ N に値のみ貼り付け
- `npm run verify:slugs` で既存 slug 無変更を再確認
